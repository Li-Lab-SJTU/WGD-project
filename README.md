These files and codes are needed to replicate the figures and p values for the paper *Polyploidization Events Increase the de novo Gene Gain Rate by Duplicating Non-Coding Regions*

To use the modified Blomberg's K function the input should meet the following format:

de_novo_counts[2:11] = c(730,306,306,71,1430,1483,957, 185,824,97) 

While the tree must be inputed as NEXUS format tree.

The files to create the figures 3 and 4 are pairedtest.txt and nodes.txt
